# Power Codes — automatic task rules

Read AGENTS.md, CLAUDE.md and authorised plans first. Existing project rules always win.

Select applicable procedures automatically:
- Build: inspect implementation, plan, implement, test and review.
- Debug: reproduce, identify root cause, fix and add regression tests.
- Security: check permissions, validation, secrets and abuse cases.
- Tenant: prove data isolation and negative permission tests.
- Payments: verify server-side amounts, webhook signatures, idempotency and reconciliation.
- Database: ensure migration safety, constraints and rollback.
- Frontend: check mobile, accessibility, errors, loading and reduced motion.
- 3D: verify realistic scale, camera, performance and device fallbacks.
- SEO: check indexing, metadata, canonical URLs and sitemap.
- Performance: measure, optimise and measure again.
- Release: run relevant checks, document rollback and obtain owner approval before production deployment.
- Privacy: minimise data exposure and follow the project's safeguarding rules.

Never claim unrun tests passed. Report changes, evidence, remaining risks and PR status.
